Rowboat

Open-source AI coworker that builds and maintains a persistent knowledge graph from your work context, enabling grounded artifact generation and background agents.

Launch Application GitHub Repository Official Site
Overview

Rowboat is a local-first AI coworker that accumulates context from your work over time rather than starting fresh with each request. It maintains an Obsidian-compatible vault of plain Markdown notes with backlinks — a transparent, editable "working memory" you can inspect and edit directly.

Unlike retrieval-augmented approaches that reconstruct context on demand, Rowboat's knowledge graph grows persistently, tracking decisions, open questions, and project threads across your email, meetings, and notes. All data remains on your machine regardless of which AI model is used.

Built by Rowboat Labs (Y Combinator S24), the project is Apache 2.0 licensed with 8,200+ GitHub stars and active community development.

Core Capabilities
Knowledge Graph
Maintains an Obsidian-compatible Markdown vault with backlinks as persistent, inspectable working memory.
Context Accumulation
Retains and compounds context over time — past decisions, open questions, and thread history — without re-ingesting each session.
Artifact Generation
Creates PDFs, email drafts, briefs, documents, and presentation slides grounded in your accumulated historical context.
Meeting Prep
Pulls past decisions, open questions, and relevant threads into cohesive briefings before each meeting.
Background Agents
Automates routine tasks — drafting email replies, daily voice summaries, project updates — without explicit requests.
Voice Notes
Records audio and automatically extracts key takeaways into the knowledge graph via Deepgram transcription.
Integrations
Gmail — email ingestion and reply drafting
Granola — meeting notes extraction
Fireflies — meeting transcript ingestion
Deepgram — voice transcription (optional)
Brave Search / Exa Search — web research (optional)
