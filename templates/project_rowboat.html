// EXECUTIVE SUMMARY

Rowboat is a local-first AI construct that accumulates context from operational directives over time rather than starting fresh with each execution. It maintains an Obsidian-compatible vault of plain Markdown intelligence with backlinks — a transparent, editable "working memory" core you can inspect and manipulate directly.

Unlike volatile retrieval-augmented approaches that reconstruct context on demand, Rowboat's knowledge graph grows persistently, tracking tactical decisions, open inquiries, and operational threads across comms and logs. All data remains isolated to the local hardware regardless of which neural model is utilized.

Developed by Rowboat Labs (CLASSIFIED ORIGIN: YC S24), the project is deployed under Apache 2.0 with significant external backing and active community reinforcement.

// CORE CAPABILITIES
Knowledge Graph
Maintains an Obsidian-compatible Markdown vault with backlinks as persistent, inspectable working memory.
Context Accumulation
Retains and compounds context over time — past decisions, open questions, and thread history — without re-ingesting each session.
Artifact Generation
Creates intelligence briefs, comms drafts, documents, and presentation slides grounded in accumulated historical context.
Briefing Prep
Pulls past decisions, open questions, and relevant threads into cohesive briefings before each scheduled operational meeting.
Background Agents
Automates routine tasks — drafting comms replies, daily voice summaries, mission updates — without explicit requests.
Voice Intercept
Records audio and automatically extracts key takeaways into the knowledge graph via Deepgram transcription.
